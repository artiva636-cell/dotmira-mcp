# MCP-сервер и API Dotmira

У Dotmira есть API. Это два программных интерфейса: **MCP-сервер** — для ИИ-ассистентов, ИИ-агентов и редакторов кода: Claude, ChatGPT, Cursor, VS Code и любого другого клиента MCP, — и **реестр компонентов, совместимый с shadcn**, — для установки из командной строки. Ассистент сам находит в каталоге нужный веб-эффект, анимацию или UI-компонент и получает его код с автором, источником и лицензией.

[Аккаунт → MCP и реестр](https://dotmira.ru/ru/account#mcp)

## Коротко

| Что | Значение |
| --- | --- |
| MCP-сервер | `https://dotmira.ru/mcp` — удалённый сервер, устанавливать ничего не нужно |
| Протокол | Model Context Protocol (MCP), транспорт Streamable HTTP; спецификация 2026-07-28, клиенты прежних версий тоже подключаются |
| Вход | через аккаунт Dotmira (OAuth 2.1) или по личному токену (Authorization: Bearer dtm_…) |
| Инструменты | `search_effects`, `get_effect`, `list_categories`, `get_preview` — только чтение |
| Реестр | `https://dotmira.ru/r/{name}.json`, имя @dotmira, формат реестра shadcn |
| Каталог | более 31 000 веб-эффектов, анимаций, UI-компонентов и шаблонов: React, Tailwind, HTML/CSS, TypeScript, Vue |
| Чего нет | REST- и GraphQL-API, SDK, описания OpenAPI, собственного CLI |

## MCP-сервер

Сервер работает по открытому протоколу MCP (Model Context Protocol), транспорт Streamable HTTP. Это удалённый сервер: устанавливать на компьютер ничего не нужно — достаточно адреса и входа.

### Адрес сервера

- dotmira.ru `https://dotmira.ru/mcp`
- dotmira.com `https://dotmira.com/mcp`

У каждого сайта свой адрес. Ассистент, подключённый через вход, работает только на том сайте, где вы разрешили доступ.

### Инструменты: что может ассистент

- `search_effects` — поиск по каталогу по словам, разделу и технологии; возвращает названия, авторов и ссылки, без кода.
- `get_effect` — код одного элемента: файлы, зависимости, лицензия, автор и источник, команда установки из реестра.
- `list_categories` — дерево разделов каталога с числом элементов в каждом.
- `get_preview` — ссылка на картинку-превью и на страницу элемента с живым превью.

Инструменты только читают каталог и ничего не меняют в вашем аккаунте.

### Что можно попросить

- «Найди в Dotmira кнопку со свечением для React и добавь её в проект».
- «Покажи пять анимированных фонов на Tailwind из Dotmira со ссылками на превью».
- «Какие разделы есть в каталоге Dotmira?»

### Ассистенты со входом через аккаунт: Claude, ChatGPT

В настройках коннекторов ассистента добавьте адрес сервера `https://dotmira.ru/mcp`, войдите в Dotmira и нажмите «Разрешить» (OAuth 2.1). Так подключаются, например, claude.ai и ChatGPT. Где находятся эти настройки, зависит от ассистента и вашей учётной записи в нём.

Ассистент получает доступ только к каталогу: ваше имя, e-mail, телефон и платежи он не видит. Отозвать доступ можно в любой момент в аккаунте («Подключённые приложения») или удалив коннектор в ассистенте.

> Доступен ли сам ассистент там, где вы находитесь, решает его разработчик: Anthropic и OpenAI публикуют списки стран, где работают Claude и ChatGPT, и России в этих списках нет. MCP-сервер и реестр Dotmira от страны не зависят.

### Редакторы кода и агенты в терминале: личный токен

Cursor, VS Code, Claude Code и любой другой клиент MCP, который подключает удалённые серверы и умеет передавать заголовки, работают по личному токену. Токен создаётся в аккаунте, в разделе «MCP и реестр», и передаётся в заголовке `Authorization: Bearer dtm_…`.

| Параметр | Значение |
| --- | --- |
| Адрес (URL) | `https://dotmira.ru/mcp` |
| Транспорт | Streamable HTTP (в настройках клиентов — «HTTP» или «streamable-http») |
| Заголовок | `Authorization: Bearer <ваш токен>` |

Cursor — файл `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "dotmira": {
      "url": "https://dotmira.ru/mcp",
      "headers": {
        "Authorization": "Bearer ${env:DOTMIRA_TOKEN}"
      }
    }
  }
}
```

VS Code — файл `.vscode/mcp.json` (токен VS Code спросит при первом подключении):

```json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "dotmira-token",
      "description": "Dotmira token (dtm_…)",
      "password": true
    }
  ],
  "servers": {
    "dotmira": {
      "type": "http",
      "url": "https://dotmira.ru/mcp",
      "headers": {
        "Authorization": "Bearer ${input:dotmira-token}"
      }
    }
  }
}
```

Claude Code — выполните в терминале:

```sh
claude mcp add --transport http dotmira https://dotmira.ru/mcp \
  --header "Authorization: Bearer $DOTMIRA_TOKEN"
```

### Проверка подключения

Прямой запрос к серверу — для проверки токена и подключения:

```sh
curl -s https://dotmira.ru/mcp \
  -H "Authorization: Bearer $DOTMIRA_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"search_effects","arguments":{"query":"glow button","limit":3}}}'
```

Сервер отвечает потоком событий: в строке `data:` — сообщение MCP (JSON-RPC) со списком найденных элементов, без кода.

## Реестр компонентов (shadcn)

Реестр @dotmira работает с shadcn CLI: команда `npx shadcn@latest add` кладёт файлы элемента прямо в ваш проект. Нужен тот же личный токен.

Для программ реестр — это HTTP-адрес: запрос `GET https://dotmira.ru/r/<id>.json` с токеном возвращает элемент в формате реестра shadcn (JSON).

Коды ответа:

- `401` — нет токена или он неверный
- `403` — доступ к коду для этого аккаунта закрыт
- `404` — нет такого элемента
- `429` — слишком много запросов, повторите позже

1. Создайте личный токен: [Аккаунт → MCP и реестр](https://dotmira.ru/ru/account#mcp) → «Создать токен».
   Скопируйте токен сейчас: он показывается один раз. Dotmira хранит только его отпечаток.
2. Добавьте реестр в файл `components.json` вашего проекта:

   ```json
   {
     "registries": {
       "@dotmira": {
         "url": "https://dotmira.ru/r/{name}.json",
         "headers": {
           "Authorization": "Bearer ${DOTMIRA_TOKEN}"
         }
       }
     }
   }
   ```

3. Сохраните токен в `.env.local` (не добавляйте этот файл в git) и установите элемент:

   ```sh
   # .env.local
   DOTMIRA_TOKEN=dtm_…
   
   npx shadcn@latest add @dotmira/glow-button
   ```

- Id элемента — в адресе его страницы (`…/e/<id>`) или в ответе `search_effects`.
- React-элементы ставятся со своими файлами и npm-зависимостями, элементы на HTML/CSS — файлами в `components/dotmira/<id>/`.
- В каждом файле есть комментарий с автором, источником и лицензией и ваша персональная метка.
- MCP-сервер самого shadcn (`npx shadcn@latest mcp`) тоже понимает этот реестр: можно попросить ассистента добавить `@dotmira/glow-button`.

## ИИ-агентам и автоматизации

ИИ-агент, который действует по поручению пользователя, получает код только через MCP-сервер или реестр — по входу или токену этого пользователя. Автоматический обход сайта, парсинг страниц и сбор кода любым другим способом запрещены Пользовательским соглашением (п. 5.1). Использовать материалы каталога для обучения моделей ИИ тоже запрещено (п. 5.1 и 5.3), в том числе материалы, полученные через MCP-сервер и реестр. Поисковые системы и ИИ-сервисы поиска и ответов могут показывать и цитировать открытые страницы со ссылкой на сайт (п. 4.3).

## Правила

- Подключайте MCP-сервер и реестр только к ассистентам, которые не используют ваши данные для обучения, или отключите такое использование в настройках ассистента — это условие [Лицензии](https://dotmira.ru/ru/legal/subscriber-license) (п. 5.2).
- Токен показывается один раз: Dotmira хранит только его отпечаток. Отозванный токен сразу перестаёт работать.
- Доступ — личный. Не передавайте токен и доступ к аккаунту никому, в том числе коллегам и клиентам.
- Не удаляйте из кода сведения об авторе, источнике и лицензии и вашу персональную метку и не публикуйте код каталога как набор компонентов.

Полные условия: [Лицензия](https://dotmira.ru/ru/legal/subscriber-license) и [Пользовательское соглашение](https://dotmira.ru/ru/legal/terms).

## Вопросы и ответы

### Есть ли у Dotmira API?

Да. Это удалённый MCP-сервер (https://dotmira.ru/mcp) и реестр компонентов, совместимый с shadcn (https://dotmira.ru/r/{name}.json). Оба работают по открытым протоколам. REST- и GraphQL-API, SDK и описания OpenAPI нет.

### Есть ли у Dotmira MCP-сервер?

Да: удалённый MCP-сервер по адресу https://dotmira.ru/mcp, транспорт Streamable HTTP, вход через аккаунт (OAuth 2.1) или по личному токену. У сервера четыре инструмента только для чтения: search_effects, get_effect, list_categories и get_preview.

### С какими ИИ-ассистентами и редакторами кода он работает?

С любым клиентом MCP, который подключает удалённые серверы по Streamable HTTP. На этой странице есть инструкции для claude.ai, ChatGPT, Cursor, VS Code и Claude Code.

### В каких странах это работает?

Доступен ли сам ассистент там, где вы находитесь, решает его разработчик: Anthropic и OpenAI публикуют списки стран, где работают Claude и ChatGPT, и России в этих списках нет. MCP-сервер и реестр Dotmira от страны не зависят.

### Есть ли REST-API, SDK или описание OpenAPI?

Нет. Программы работают с Dotmira через MCP-сервер и реестр. Реестр отвечает на обычные HTTP-запросы данными в формате JSON; MCP-сервер отвечает на запросы JSON-RPC по HTTP.

### Можно ли обращаться к API из своей программы, без ИИ-ассистента?

Да — со своим личным токеном. Извлекать каталог целиком или его существенную часть запрещено (Лицензия, п. 5.1).

### Что ассистент узнаёт о моём аккаунте?

Ничего, кроме каталога. Имя, e-mail, телефон и платежи ассистент не видит. Доступ можно отозвать в любой момент в аккаунте («Подключённые приложения»).

### Есть ли инструмент для командной строки?

Своего CLI у Dotmira нет: элементы устанавливаются через shadcn CLI — npx shadcn@latest add @dotmira/<id>.

### Может ли ИИ-агент сам обходить сайт и копировать код?

Нет. Код выдаётся только на сайте, через MCP-сервер и через реестр. Автоматический обход сайта и сбор кода запрещены Пользовательским соглашением (п. 5.1).

### Можно ли использовать код для обучения моделей ИИ?

Нет. Это запрещено Пользовательским соглашением (п. 5.1 и 5.3) и Лицензией (п. 5.1 и 5.2). Подключайте только ассистентов, которые не обучаются на ваших данных.

### Чем MCP-сервер отличается от реестра?

MCP-сервер позволяет ассистенту искать по каталогу и получать код прямо в разговоре. Реестр ставит элемент по его id одной командой. Личный токен у них общий.

### Где взять id элемента?

В адресе страницы элемента (…/e/<id>) или в ответе search_effects.
